# Application icon

The supplied application icon shows a red F and blue gear inside braces. Its source PNG images are in [`icons/`](icons/) at 16, 20, 24, 32, 48, 64, 128 and 256 pixels.

`FreeCADMCPServer.ico` packages all eight PNG images unchanged for Windows shortcuts. The Start menu shortcut installer uses this file; rerun setup to create or update the shortcut.
